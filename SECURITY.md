# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

This is a single-user local-first application. The backend binds to localhost
only and is not designed for multi-user or public network access.

If you discover a security vulnerability, please open an issue with the label
`security` rather than a public discussion. Provide a clear description of
the issue and steps to reproduce.

We do not currently have a dedicated security mailing list. For sensitive
reports, please reach out through the GitHub issue tracker with as much
detail as possible.
